## Acceptance record

On first-run setup, ScarletX requires the operator to scroll through the agreement, explicitly check the acceptance box, and continue before an administrator can be created. ScarletX stores the acceptance timestamp and agreement version in the installation configuration.

The acceptance record is installation configuration and is intentionally preserved when the operator uses **Start Over** to reset library data.
