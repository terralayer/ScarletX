# ScarletX 0.3.9 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release ScarletX 0.3.9 with the approved security, correctness, performance, and supply-chain hardening while preserving 0.3.8 behavior and data compatibility.

**Architecture:** Keep the Nginx + private FastAPI split. Add small focused security/performance helpers rather than expanding the 130 KB legacy `main.py`; wire them into existing flows with minimal edits. All release metadata moves to 0.3.9 only after implementation verification.

**Tech Stack:** Python 3.11+, FastAPI, SQLAlchemy, SQLite/WAL, cryptography/Fernet, Nginx, Docker, GitHub Actions, TrueNAS Community Apps tooling.

**Spec:** `docs/superpowers/specs/2026-09-01-0.3.9-hardening-design.md`

## Global Constraints

- Release is exactly `0.3.9`; do not change the first or second version component.
- Nginx is the only public HTTP service; backend remains internal on port 8000.
- Existing 0.3.8 databases/storage must upgrade in place.
- TrueNAS SCALE compatibility is required.
- No unrelated feature work.
