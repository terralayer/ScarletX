# ScarletX 0.4.0

ScarletX 0.4.0 introduces the approved redesigned dashboard and branding as the new release line.

Highlights:
- New ScarletX ribbon wordmark and application icon.
- Full-width dark dashboard shell with the approved header, sidebar, hero, statistics, recent scenes, upcoming releases, and footer layout.
- Existing ScarletX metadata, monitoring, library, search, downloader, and TrueNAS behavior retained.
- Fresh-install indexer placeholders remain blank while generic indexer functionality stays available.
- 0.4.x becomes the active release series for future patch releases.
