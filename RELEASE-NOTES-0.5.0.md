# ScarletX 0.5.0

ScarletX 0.5.0 packages the current library reliability, playback, download-management, search, and deployment updates.

- Main library views now show scenes, performers, and studios based on directly monitored scenes.
- Adds performer and studio monitoring controls, scene playback actions, and release-date file ordering.
- Adds a compact SABnzbd-style Downloads queue with live status, speed, ETA, and consistent row actions.
- Adds clear-downloads and Start Over controls with configuration and indexer settings preserved.
- Improves search fallback behavior, remote performer/studio profile loading, pagination, artwork handling, and local container deployment.
- Includes expanded regression coverage for library filtering, playback, downloads, setup, and deployment contracts.
