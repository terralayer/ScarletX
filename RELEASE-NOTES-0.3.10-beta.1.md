# ScarletX 0.3.10-beta.1

This is the first beta of the ScarletX 0.3.10 whole-app optimization release.

## Highlights

- Query indexes and lightweight list APIs for faster large-library views.
- TPDB in-memory caching and request coalescing.
- Throttled download-progress persistence and incremental library scanning.
- Duplicate media-processing suppression and a global queue event stream.
- Bounded download/post-processing pipeline with phase metrics and retry-preserved partial work.
- Backend/frontend module decomposition with externalized frontend assets.
- Packaging and deployment optimization with digest-pinned bases, private backend networking, persistent backups, and strengthened release validation.

## Beta note

This prerelease is intended for validation before the final 0.3.10 release. The stable main branch remains on 0.3.9.
